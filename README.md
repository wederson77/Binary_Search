# Binary Search in Rust  

This repository contains a simple implementation of the binary search algorithm in Rust.  
Binary search efficiently finds an element in a sorted list by repeatedly dividing the list in half.  

## Project Structure  

- **src/** – Algorithm implementation and tests  
- **Cargo.toml** – Project configuration and dependencies  

## Requirements  

- **Rust** – Install from [rust-lang.org](https://www.rust-lang.org/tools/install)
